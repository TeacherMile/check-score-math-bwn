# ระบบดูคะแนนสอบ — กิจกรรมพัฒนาศักยภาพสู่ความเป็นเลิศทางคณิตศาสตร์ ปีการศึกษา 2569

เว็บไซต์ให้นักเรียน **เข้าดูคะแนนของตนเอง** ด้วย **เลขประจำตัวนักเรียน + หมายเลขโทรศัพท์**
โดยมีหน้าสำหรับ **ครู (แอดมิน)** เป็นผู้กรอกคะแนนและข้อที่ผิดเอง

- 👩‍🎓 หน้านักเรียน: `index.html`
- 🔑 หน้าครู (แอดมิน): `admin.html`

---

## ความเป็นส่วนตัว / ความปลอดภัย (สำคัญ)

- เว็บนี้เป็นเว็บสาธารณะ (GitHub Pages) แต่ **ไฟล์ที่เผยแพร่มีเพียง "เลขประจำตัวนักเรียน" กับข้อมูลที่เข้ารหัสไว้เท่านั้น** — ไม่มีชื่อ ไม่มีเบอร์โทร ไม่มีคะแนนแบบอ่านออกได้
- ข้อมูลของนักเรียนแต่ละคน (ชื่อ, ห้อง, คะแนน, ข้อที่ผิด) ถูก **เข้ารหัส (AES-GCM) ด้วยเบอร์โทรของคนนั้น** — ต้องกรอกเบอร์ถูกจึงถอดดูได้
- ไฟล์ที่มีเบอร์โทรจริง (`roster_private.json`) **ถูกตั้งค่าไม่ให้ขึ้น repo** (อยู่ใน `.gitignore`) → คุณครูเก็บไว้ในเครื่องตัวเองเท่านั้น

> ⚠️ ห้ามอัปโหลดไฟล์ `roster_private.json` ขึ้น GitHub เด็ดขาด เพราะมีเบอร์โทรนักเรียน

## โครงสร้างไฟล์

```
index.html              หน้านักเรียน (ดูคะแนน) — เข้าด้วยเลขประจำตัว + เบอร์โทร
admin.html              หน้าครู (กรอกคะแนน)
data/
  records.json          ข้อมูลนักเรียน (ชื่อ+ห้อง+คะแนน+ข้อที่ผิด) เข้ารหัสแล้ว — เผยแพร่ได้
build/
  crypto-core.mjs       โค้ดเข้ารหัส/ถอดรหัส (ใช้ร่วมกันทั้งหน้าเว็บและตัวสร้างไฟล์)
  generate.mjs          สคริปต์สร้างไฟล์ data/records.json จากไฟล์รายชื่อ (ใช้ผ่าน Node)
roster_private.json     ⛔ ไฟล์รายชื่อ+เลขประจำตัว+เบอร์โทร (ไม่ขึ้น repo, เก็บในเครื่องครู)
```

## วิธีเปิดใช้งานเว็บ (ครั้งแรก)

1. ไปที่ **Settings → Pages** ของ repo นี้
2. ที่ **Build and deployment → Source** เลือก **GitHub Actions**
3. รอสักครู่ ระบบจะเผยแพร่เว็บอัตโนมัติ (มี workflow อยู่ที่ `.github/workflows/deploy-pages.yml`)
4. เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/check-score-math-bwn/`
   - นักเรียนเข้าที่หน้าหลัก (`index.html`)
   - ครูเข้าที่ `.../admin.html`

> ข้อมูลนักเรียน 217 คน (พร้อมเลขประจำตัวจริง) และคะแนน 20 คนจากรูป ถูกใส่ไว้ให้แล้ว ใช้งานได้ทันที

---

## วิธีของครู: กรอก/แก้ไขคะแนน แล้วอัปเดตเว็บ

1. เปิดหน้า `admin.html` → ใส่รหัสผ่านแอดมิน (เริ่มต้น: `mathadmin`)
2. **ขั้นที่ 1** กด "เลือกไฟล์" แล้วเลือกไฟล์ `roster_private.json` ที่เก็บไว้ในเครื่อง
3. **ขั้นที่ 2** กรอก **คะแนน** และ **ข้อที่ผิด** (พิมพ์เลขข้อคั่นด้วยจุลภาค เช่น `3, 7, 12`)
   - ปรับ "คะแนนเต็ม" ได้ (ค่าเริ่มต้น 30)
   - ช่องค้นหาไว้หาเลขประจำตัว/ชื่อนักเรียนได้เร็วขึ้น
   - เพิ่ม/แก้เบอร์โทร หรือเลขประจำตัว ได้ในช่องของแต่ละคน
4. กด **💾 บันทึกไฟล์รายชื่อ** เพื่อเก็บ `roster_private.json` ฉบับล่าสุดไว้ (ใช้แก้ครั้งหน้า)
5. กด **📤 สร้างไฟล์สำหรับเผยแพร่** → จะได้ไฟล์ `records.json` (ใช้เวลาสร้างสองสามวินาที)
6. นำไฟล์นั้นไปวางแทนของเดิมในโฟลเดอร์ `data/` ของ repo:
   - วิธีง่ายสุด: เปิด GitHub → เข้าโฟลเดอร์ `data/` → **Add file → Upload files** → ลากไฟล์ลงไป → **Commit**
   - GitHub Pages จะอัปเดตเว็บให้อัตโนมัติ นักเรียนเห็นคะแนนใหม่ทันที

> หมายเหตุ: นักเรียน 2 คนในข้อมูลเดิมมีปัญหาเรื่องเบอร์โทร (เลขประจำตัว 49127 เบอร์ผิดรูปแบบ, 47443 ไม่มีเบอร์)
> จึงยังเข้าดูคะแนนไม่ได้จนกว่าครูจะแก้/เพิ่มเบอร์ให้ในหน้าแอดมิน

## สำหรับผู้ดูแลระบบ (ทางเลือก): สร้างไฟล์ผ่าน Node

```bash
node build/generate.mjs roster_private.json data
```

รูปแบบ `roster_private.json` เป็น array ของ:
```json
{ "no": 1, "student_id": "49077", "prefix": "นาย", "first": "ชื่อ", "last": "สกุล",
  "classroom": "ม.4/3", "phone": "0800000000", "score": 22, "max": 30, "wrong": [3, 7] }
```

## เปลี่ยนรหัสผ่านแอดมิน

แก้ตัวแปร `ADMIN_PASSWORD` ในไฟล์ `admin.html`
